# Marvel Sentry + Void Mod

The Marvel Sentry + Void Mod is a Minecraft mod that adds the iconic Marvel characters Sentry and Void to the game. This mod features the Sentry with his golden suit, powerful abilities, and the Void with his dark, tattered cape and unique powers. The mod includes custom skins, animations, and abilities for both characters, allowing players to experience the power and style of these Marvel heroes in the Minecraft world.

## Install

1. Download the mod from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Obtain the Serum item to transform into Sentry or Void.
2. Right-click the Serum item to transform.
3. Use the abilities of Sentry or Void by right-clicking with the respective item in hand or using the custom GUI.
